# Сервер BMS

Решение `Bms.Backend.slnx` содержит четыре продуктовых проекта:

- `Bms.Domain` - доменная модель и правила документов.
- `Bms.Application` - операции приложения, контракты и DTO.
- `Bms.Infrastructure` - EF Core, SQL Server, вложения и интеграционные адаптеры.
- `Bms.Api` - HTTP API, аутентификация, диагностика и фоновые обработчики.

Тестовые проекты не включены в публичный кандидат. Сборка выполняется командой
`dotnet build Bms.Backend.slnx -c Release`. Закреплённые версии SDK и runtime
нужно соблюдать; успешная компиляция не подтверждает наличие runtime на машине.

Начальные настройки включают Windows Authentication, CSRF и режим обслуживания
без записи. Строка подключения отсутствует, роли сотрудников не назначены,
фоновые интеграции выключены. Не разрешайте development actor headers для
обхода настройки Windows-входа.

Порядок установки, права служебного пользователя, настройка HTTPS, реплики и
вложений описаны в `../docs/INSTALLATION.md`. Автоматического изменения
существующей БД при запуске API нет.
