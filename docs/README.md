# Документация BMS · Версия 1.0

BMS — Budget Management System, система управления бюджетами компании.
Публичное обозначение версии — 1.0; техническая основа — catalog485.
Документы описывают версию BMS 1.0 с нейтрально-серой темой, а не текущую работу
исходной компании и не обещания из раннего ТЗ. Комплект обновлён 29 октября 2026 года.

## Как читать доказательства

Ссылки «Реализация» ведут в исходники этого же пакета. Это подтверждение наличия
контракта или правила в коде, но не доказательство успешной работы в новой инфраструктуре.
Скриншоты показывают настоящий React-интерфейс с синтетическими ответами API;
они не являются протоколом серверной приёмки. В них нет данных компании.

Архив не содержит SQL-БД, резервных копий, паролей, сотрудников, бюджетов,
платёжных выгрузок или тестовых проектов. Windows/AD и Microsoft SQL Server
нужны для полноценного нового развёртывания. Готовность исходников к просмотру
не означает готовность новой установки к эксплуатации.
