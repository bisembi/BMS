# Проверки BMS 1.0

## Подготовка исходного пакета

| Проверка | Результат |
| --- | --- |
| TypeScript и production-сборка Vite | Успешно |
| Четыре серверных проекта Release | Успешно, без предупреждений |
| Еженедельный обработчик | Успешно, без предупреждений |
| Манифест | Контрольные суммы всех файлов проверены |
| SQL, PowerShell и JSON | Синтаксическая проверка без ошибок |
| Документация | Локальные ссылки, изображения и навигация проверены |
| HTML-руководство | 23 раздела; desktop и узкое отображение проверены |
| Иллюстрации | 20 скриншотов с вымышленными данными |

Интерфейс использует нейтрально-серую тему. Скриншоты получены с локальной
production-сборки с синтетическими ответами API и не являются доказательством
серверной транзакции. В продукте нет транспорта подмены API.

В локальной проверке установщика создавалась пустая основная БД: 60 версий
миграций до версии 61, 79 таблиц `bms_web` и 3 таблицы `bms_version454`.
Проверены признак владения установкой, первичный технический администратор,
идемпотентный повтор, Windows-вход и отказ при выборе неназначенной роли.
Эти результаты не подтверждают настройку инфраструктуры другой организации.

## До рабочего внедрения

**Штатный обмен с 1С пока не реализован.** Требуются адаптер, публикация
собственной витрины, согласованные сопоставления и сверка с источником.
Сценарии, зависящие от этого факта, до приёмки транспорта имеют статус BLOCKED.

Нужны полный финансовый цикл под реальными ролями, конкуренция, повторы,
сканирование вложений, SMTP, резервирование и проверенное восстановление.
Успешная сборка и манифест не заменяют бизнес-приёмку или аудит безопасности.
