# Обмен и локальные обработчики BMS

Каталог содержит локальные обработчики данных BMS. Штатный обмен с 1С
пока не реализован; его целевая архитектура описана в документации.

## Состав каталога

| Каталог | Назначение | Граница |
| --- | --- | --- |
| [weekly](weekly) | Исходники недельных напоминаний о первичке | Читают собственные таблицы `bms_web` |
| [dds](dds) | SQL чтения расшифровок | Читает собственную витрину BMS |

Сборка недельного обработчика не запускает рассылку:

```powershell
dotnet build integrations/weekly/Bms.WeeklyPrimary425.csproj -c Release
```

Недельный обработчик сохраняет проверки хоста, службы, путей, хешей,
SQL-полномочий, адресатов и журнала попыток. Их нужно привязать к своей
установке после проверки, а не удалить ради запуска. Учебный профиль статей
не является согласованной политикой вашей компании. SMTP и расписания
не настроены; отправка не выполняется автоматически.

## Целевой обмен с 1С

Использовать документированные механизмы платформы: HTTP-сервис, OData,
Web-сервис либо файловую выгрузку, сформированную средствами 1С. Данные
проходят отдельный адаптер, сверку и атомарную публикацию собственной витрины BMS.

**Адаптер, контракт выгрузки конкретной конфигурации и полный установщик
витрины пока не реализованы в этом пакете.** SQL-читатели работают
с контрактами собственной витрины BMS. Отсутствие факта
не должно превращаться в успешный пустой снимок или ручное подтверждение оплаты.

Проектирование и приёмка: [руководство интеграции](../docs/INTEGRATION_GUIDE.md).
Лицензионная граница: [условия интеграции](../docs/INTEGRATION_LICENSING.md).
